### 💼 Featured Projects

<table>
<tr>
<td width="50%" valign="top">

**🧠 Bengali NLP Text Classifier**
<br/>
Fine-tuned **BanglaBERT** on a ~17.9k sample dataset to classify text into *Depressive*, *Non_depressive*, and *Positive* categories. Built an automated labeling pipeline using Gemini & Groq APIs with checkpoint/resume logic for large-scale Kaggle runs, and iterated on learning rate, dropout, and label smoothing to improve class separation.
<br/><br/>
`Python` `BanglaBERT` `Transformers` `Kaggle` `Gemini API` `Groq API`

</td>
<td width="50%" valign="top">

**📰 MultiBanFakeDetect — Bangla Fake News Detection**
<br/>
Benchmarked **BanglaBERT, mBERT, XLM-RoBERTa, and DistilBERT-m** for binary and multi-class fake news detection in Bangla. BanglaBERT led with peak F1 ≈ 0.808; used Focal Loss to handle class imbalance in the multi-class setting. Findings documented in a technical report.
<br/><br/>
`Python` `PyTorch` `Transformers` `Focal Loss`

</td>
</tr>
